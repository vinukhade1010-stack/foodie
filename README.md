# 🍔 Foodie: Food Ordering Web App

A full-stack food ordering web application built with **Java Servlets, JSP, JDBC, and MySQL**, featuring a modern JavaScript front end communicating via asynchronous AJAX (JSON) endpoints.

---

## 🛠️ Tech Stack & Requirements
* **Backend:** Java 11+, Apache Tomcat 9 (`javax.servlet` — *Note: Tomcat 10+ uses `jakarta.servlet` and will require code changes*), Maven
* **Database:** MySQL 8
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (AJAX)

---
